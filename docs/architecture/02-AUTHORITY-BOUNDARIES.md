# FALCON Authority Boundaries

## HERMES

Owns market truth and provenance. FALCON stores bounded
decision-relevant HERMES evidence, not the full raw MBP/tick/research
corpus.

## Canonical ARES

Owns ARES context truth and authoritative SQL history. Current canonical
authority is advisory. FALCON must not invent mandatory ARES veto
authority. Scheduled-event, market-status, liquidity, macro/USD and
source-quality evidence can be exported when individually registered.
Future news/AI/decision families are added only when real capabilities
exist.

## HELIOS

Owns deterministic strategy evaluation, state, chains and semantic
trigger intent. HELIOS remains execution-blind. SL/TP semantic intent
may be part of a trigger; broker-specific order mechanics remain TRON.

## TRON

Owns serviceability, admission, hard risk, quantity, broker symbol,
order type, broker constraints, execution, fills, positions, protection,
exits and outcomes.

## FALCON

Owns evidence validation, correlation, ingestion identity, field
registry, retention/search semantics and technical GUI. It must not
silently transform a producer's domain meaning.

## NEO

Consumes evidence for retrospective review/research. NEO does not
retroactively rewrite FALCON evidence.
