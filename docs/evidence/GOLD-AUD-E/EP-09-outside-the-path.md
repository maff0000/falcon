# EP-9: "FALCON outside the executable path", as testable publisher requirements

Binding guidance: FALCON is evidence-only and must not block execution. Publication is asynchronous, non-blocking and through a bounded queue; evaluation, trigger, claim, risk, order and reconcile must complete with FALCON ingestion stopped (CA guidance 2026-10-15, item 3, as applied in the PID).

## Limits of this part

1. **No timing rule is relied on.** The proposed "baseline elapsed time plus 10 percent" bound (`GOLD-MVP-001` AC-12) is **not approved** and appears in no requirement or test below. Elapsed times may be recorded as information in a rehearsal; none is a pass or fail criterion until the PO confirms a rule. Where a test needs a time limit it is a **hang detector** (the test has not returned), not a performance bound.
2. **The outage rehearsal is not run by this audit.** It needs an isolated DEV/test FALCON, and the lane forbids touching any running FALCON or Graylog. R-5 below specifies it for the follow-on work. The reference model (`ep09_reference_model.py`) demonstrates that every requirement is mechanically testable; it is a tests-only model and proves nothing about HELIOS, TRON or FALCON themselves.
3. Logical equivalence is not byte identity: same trigger dispositions, same orders, fills and position-reconciliation outcome, same terminal states; FALCON-side counters and timestamps are excluded.

## Reference model result

`python3 docs/evidence/GOLD-AUD-E/ep09_reference_model.py` runs 8 tests over a bounded drop-on-full spool, a local journal and a read trap, under six FALCON modes (ok, unreachable, rejecting, blocked, slow, full). It was run at the audit and passed (`AUDIT-LOG.md`). It contains no sleeps and no wall-clock assertion.

## Gate for the real rehearsal (follow-on work)

Preconditions: an isolated DEV/test FALCON that no other system uses; the same recorded entry replayed twice; the logical comparator of R-6 agreed in advance; the PO's decision on whether any timing rule applies (none is assumed). Postconditions: the outcome projections are equal, the FALCON-side gap is backfilled from the journals (R-9), and the run record names the isolated instance generically (no addresses or hostnames in public evidence).
