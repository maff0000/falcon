# Graylog GUI Query Catalogue

The Graylog GUI is FALCON's native technical investigation console.

## Required operator questions

-   What important ARES events are coming up?
-   What is happening in the next 30 minutes?
-   What did ARES know at exact UTC T?
-   What did HERMES see when HELIOS evaluated?
-   Why did a strategy fire, decline, block or near-miss?
-   Show a specific HELIOS Trade Suggestion and its complete causal
    timeline.
-   Did ARES state change between HELIOS Trade Suggestion and TRON
    admission?
-   Why did TRON refuse a Trade Suggestion?
-   Show all orders/fills/outcomes for one Trade Suggestion.
-   Show source-quality incidents and recovery.
-   Show provider revisions/corrections.
-   Show all evidence for one instrument over a bounded interval.
-   Show losing/winning trades around an event class.
-   Show suppressed/rejected opportunities for NEO analysis.

## Acceptance

PID-11 creates saved searches/dashboards sufficient to answer the
catalogue using only governed FALCON evidence, without querying producer
private databases for retrospective explanation.
